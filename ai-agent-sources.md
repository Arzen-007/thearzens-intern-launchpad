# Verified web AI agent sources

## Core agent platforms

| Platform | Verified capability | Free-access information | Official URL |
|---|---|---|---|
| Kimi | The web interface prompts users to “Ask anything, or task an agent” and lists agent-oriented modes including Deep Research, Docs, Websites, Sheets, and Design. | Availability and free usage are account/region dependent; verify in the live interface. | https://www.kimi.com/ |
| Genspark | Its official page calls it an all-in-one AI workspace and lists AI chat, research, site/app building, design, documents, and GenTerminal. | The page says “Try free today”; credit/model limits can change. | https://www.genspark.ai/ |
| Qwen | Qwen Studio provides a web chat interface, though the public landing page does not verify a persistent sandbox or agent runtime. | Treat as a free web-model interface, not a confirmed sandbox agent. | https://chat.qwen.ai/ |
| Google Jules | Autonomous coding agent that imports GitHub repositories, uses a Cloud VM, runs/creates tests, and opens pull requests. | The public Jules plan lists 15 tasks/day and 3 concurrent tasks. Availability can be region-dependent. | https://jules.google.com/ |
| Firebase Studio | Browser-based full-stack workspace with AI agents, codebase actions, web preview, and Android emulators. | The current page lists three no-cost preview workspaces, but it also announces a 22 March 2027 sunset and says new workspaces can no longer be created. | https://firebase.studio/ |
| Replit Agent | Browser workspace where Agent builds apps through chat, can search the web, test its own code with a browser, and connect to database/auth. | The official page says “Get started free”; credits and deployment limits must be checked in the live dashboard. | https://replit.com/ai |
| Bolt | Browser-based AI product builder that can chat-build apps, route across models, test/refactor/iterate, and use built-in backend/hosting tools. | Official page says “start building for free”; usage limits are plan-dependent. | https://bolt.new/ |
| Lovable | Web application builder that creates, runs, and manages full-stack products from natural language, with hosting and infrastructure support. | Official page says “Get started for free”; daily credits and feature access can change. | https://lovable.dev/ |

## Source notes

All availability, usage limits, country support, signup requirements, quotas, and pricing are subject to change. The public site labels will say **Free access**, **Free tasks**, **Free credits**, or **Check live limits** rather than claiming that every capability is permanently free.
