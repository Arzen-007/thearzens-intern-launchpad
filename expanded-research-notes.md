## CTF Operations and Event Discovery

| Resource | Verified purpose | Free-access note | Official URL |
|---|---|---|---|
| CTFd | Open-source framework for creating and administering CTF challenges, teams, scoring, hints, and events. | Self-hosted software is open source; CTFd’s managed hosting is separately paid. | https://github.com/CTFd/CTFd |
| CTFd documentation | Deployment guidance for the self-hosted platform. | Documentation states a minimum of 2 CPU cores and 1 GB RAM, with 4 CPU cores and 2 GB RAM recommended; Docker Compose is a documented path. | https://docs.ctfd.io/docs/deployment/installation/ |
| CTFtime | Public calendar, team rankings, results, and writeup discovery for CTF events. | The public site is accessible for event and writeup discovery; organizers must follow its registration and event rules. | https://ctftime.org/ |

The hub will explain that a free CTF framework does not include safe, persistent Docker-capable compute. Dynamic challenges should be isolated from the scoreboard and exposed only in authorized event contexts.
