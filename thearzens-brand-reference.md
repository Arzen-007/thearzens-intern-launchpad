# THE ARZENS Reference Notes

The live homepage uses a black/near-black ground, electric cyan as the primary signal color, white high-contrast typography, thin technical grid or scan-line details, and a command-console atmosphere. Its hero language is operational rather than generic: **“THE SYSTEM IS WAKING”**, **“INITIALIZE PROTOCOL”**, and **“EXPLORE ARSENAL.”**

The rebrand should preserve the existing resource depth while repositioning it as an intern-operating environment. The intended visual vocabulary is: dark surfaces, cyan highlights, optional red/purple alert states, monospace micro-labels, sharp rectangular controls, terminal-style status indicators, and security-operations language. The supplied THE ARZENS logos should be used as real brand assets, with the cyan logo as primary and red/purple as contextual alert or specialist-path accents.
