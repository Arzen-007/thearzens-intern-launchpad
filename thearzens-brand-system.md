# THE ARZENS Intern Launchpad Brand System

## Positioning

**THE ARZENS Intern Launchpad** is an operational starting point for interns who need trusted free infrastructure, practice environments, and project routes to build professionally and ethically.

## Visual Language

The experience inherits THE ARZENS’ dark command-console character: near-black surfaces, sharp panels, thin technical borders, high-contrast white type, terminal labels, and electric cyan as the primary action signal. Red is reserved for offensive-security and CTF routes; purple is reserved for AI and research routes. The language is precise, direct, and active: *Initialize a path*, *Open a resource*, *Build the stack*, and *Verify before you deploy*.

## Logo Roles

| Logo | Role |
|---|---|
| Blue / cyan mark | Primary brand mark, main navigation, default launch state |
| Red mark | Offensive-security, CTF, and red-team pathways |
| Purple mark | AI-agent, research, and advanced automation pathways |

## Interaction Model

Mission cards are the core route selector. Each mission sets the appropriate resource pathway and signals the selected context through cyan, red, or purple accents. All resource cards retain a direct official outbound link. Interactions use short, sharp state changes rather than soft editorial motion.
