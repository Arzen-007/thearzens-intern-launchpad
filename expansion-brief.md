# Expanded Platform Map

## Audiences

The platform will support four primary audiences: developers building applications; cybersecurity students learning only in authorized environments; CTF organizers and participants; and IT learners who need practical, zero-cost starting points. Each resource will state what it is for, who can use it, what “free” means, and whether account, card, region, or student-status constraints may apply.

## Core Journeys

| Journey | Starting question | Main destination |
|---|---|---|
| Build an app | “Where can I code, host, store data, and deploy?” | Builder stack with frontend, backend, database, domain, DevOps, and AI tools |
| Start cybersecurity | “What can I learn legally without paying?” | Learning paths, labs, practice platforms, blue-team, red-team, web-security, and OSINT routes |
| Run a CTF | “How do I host an event safely?” | CTF platform, infrastructure, isolation, scoring, participant communication, and backup routes |
| Find an agent | “Which web AI can actually do work?” | Clearly classified web agents, coding agents, app builders, research agents, and ordinary chat interfaces |
| Grow a career | “Which free credentials, communities, and programs help me?” | Student programs, learning libraries, free courses, developer communities, and practice roadmaps |

## Resource Categories

The discovery system will include: cloud and servers; frontend and full-stack hosting; backend and APIs; databases and storage; domains, DNS, TLS, and email; coding workspaces and source control; DevOps and observability; design and product tools; AI agents and model workspaces; cybersecurity learning; legal practice labs and CTFs; OSINT and defensive tools; CTF operations; student programs; certifications and learning; and communities and career resources.

## Safety Boundary

Cybersecurity content will link to legal training platforms, defensive tools, CTFs, and environments where users have authorization. The platform will not position third-party systems, evasion, or unauthorized activity as learning exercises.

## Discovery Metadata

Every record will use a consistent set of labels: **audience**, **skill level**, **use case**, **free model**, **account friction**, **Pakistan note**, **official link**, and **practical warning**. This lets learners compare resources without mistaking a trial, student offer, or limited credit for permanent free infrastructure.
